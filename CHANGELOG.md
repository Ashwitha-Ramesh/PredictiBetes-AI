# Release Notes & Changelog

## [v1.0.0] - 2026-08-01

### Added
- **PredictiBetes Platform Release**: Full-stack Machine Learning application developed by **Ashwitha Ramesh**.
- **6-Model Benchmarking**: Automated evaluation across Logistic Regression, Random Forest, Decision Tree, Support Vector Machine, K-Nearest Neighbors, and Gaussian Naive Bayes.
- **Explainable AI (XAI)**: Feature-level risk factor contribution breakdown.
- **Interactive Analytics**: Plotly correlation heatmaps, class distributions, histograms, and scatter plots.
- **Prediction History**: SQLite database persistence with search, risk filter badges, individual delete, and CSV export.
- **Batch CSV Processing**: Drag-and-drop file upload for multi-patient risk assessment.
- **Cloud Deployment Compatibility**: Environment variable `PORT` binding for Render, Railway, Koyeb, and Heroku.
